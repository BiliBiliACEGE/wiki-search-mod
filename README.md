# Wiki Search Mod

一个Minecraft Fabric模组，允许玩家在游戏中直接搜索Minecraft Wiki。

## 功能

- 在游戏中直接搜索Minecraft Wiki
- 支持多语言Wiki站点自动切换
- 可自定义搜索链接模板
- 快捷键快速打开搜索界面

## 安装

1. 确保已安装Fabric Loader和Fabric API
2. 将模组jar文件放入`mods`文件夹
3. 启动游戏

## 使用方法

- 默认快捷键`Ctrl+W`打开搜索界面
- 输入搜索内容后按回车或点击搜索按钮
- 在设置中可配置自动语言检测和自定义搜索链接

## 配置

- `自动检测语言`: 根据游戏语言自动选择Wiki站点
- `自定义搜索链接`: 使用`%s`作为搜索词占位符
